# Image generation ONLY — no coding

Your ONLY job in this session is to generate images with your
image-generation tool and save each one under `./sources/` with the exact
filename given. Do NOT write, edit, or run any Python or other code; do
not touch any other files. Shell use is allowed solely to copy each
generated image from your image cache into `./sources/<name>.png`.
Skip any filename that already exists in ./sources/.

These are textures for 3-D farm greenhouses in China, seen in a flight
simulator. They must look used and weathered, never new or clean:
irregular dust, mud, stains, patches, sagging, repairs.

Style for ALL images: photorealistic, strictly orthographic (camera
perpendicular to the surface), flat overcast lighting, no directional
shadows, no perspective, no vignetting, no text, no watermarks, no people,
the material fills the whole frame edge to edge.
