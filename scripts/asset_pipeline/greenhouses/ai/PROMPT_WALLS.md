# Image generation ONLY — no coding

Your ONLY job in this session is to generate images with your
image-generation tool and save each one under `./sources/` with the exact
filename given. Do NOT write, edit, or run any Python or other code; do
not touch any other files. Shell use is allowed solely to copy each
generated image from your image cache into `./sources/<name>.png`.
Skip any filename that already exists in ./sources/.

These are wall textures for north-China vegetable greenhouses in a flight
simulator. The walls must read clearly as BUILT masonry walls of a farm
building -- straight courses, straight edges, man-made materials -- never
as earth, rock, cliffs or terrain. Used and weathered: dust, mud splash,
rain streaks, patches, but still obviously a building.

Style for ALL images: photorealistic, strictly orthographic straight-on
view (camera perpendicular to the wall), flat overcast lighting, no
directional shadows, no perspective, no vignetting, no text, no people,
the wall fills the whole frame edge to edge with no sky and no ground
beyond a thin strip of soil at the very bottom edge.
