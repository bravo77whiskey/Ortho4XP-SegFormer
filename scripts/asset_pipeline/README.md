# O4SFR_Library asset pipeline

Builds the shipped X-Plane 12 building object library `O4SFR_Library/` from a
curated catalog of open-source 3D models. The library is consumed by the SFR
building overlay through the existing `library.txt` plumbing — see
`CURATED_EXTRA_BUILDING_LIBRARIES["o4sfr"]` in
[`src/O4_SFR_Building_Overlay.py`](../../src/O4_SFR_Building_Overlay.py).

## Why this pipeline

The SFR building overlay places objects from `BLD_CLASS_*` pools. Existing
external XP libraries (OpenSceneryX, world-models, R2_Library, CDB-Library,
Handy Objects) skew Western and small. This pipeline:

- Pulls CC0 / CC-BY 3D models authored outside the X-Plane ecosystem.
- Sorts them into one of the natural-earth regions used by the overlay
  (`europe`, `scandinavia`, `mediterranean`, `north_america`, `south_america`,
  `asia`, `se_asia`, `africa`, `australia_oceania`, plus `generic`).
- Converts each model to X-Plane `.obj` via headless Blender +
  [xplane2blender](https://github.com/X-Plane/XPlane2Blender).
- Emits a `library.txt` whose virtual paths carry the region as a token
  (`o4sfr/<region>/<bucket>/<asset>.obj`) so the overlay's path-token regional
  routing picks the right asset for each tile.

**Out of scope:** sourcing from OSM/OSM2World. The whole project exists to fill
OSM gaps; pulling buildings back from OSM defeats the intent. Authored 3D
models only.

## Layout

```
scripts/asset_pipeline/
  sources.yaml                  # the curated catalog (manifest)
  build_custom_library.py       # manifest -> library.txt + LICENSE + ATTRIBUTIONS
  convert_to_xplane_obj.py      # headless Blender batch converter
  README.md
```

Build output (not committed) — drop next to SimHeaven in `Custom Scenery/`:

```
Custom Scenery/O4SFR_Library/
  library.txt
  LICENSE
  ATTRIBUTIONS.md
  europe/residential/townhouse_03.obj
  europe/residential/townhouse_03.png
  north_america/residential/ranch_01.obj
  ...
```

## Source providers (CC0 / CC-BY)

| Provider | License | Regional strength |
|---|---|---|
| Kenney.nl (Modular Buildings, City Kit) | CC0 | Western suburban / commercial / industrial |
| Quaternius (Modular Buildings, City Kit, Medieval Village) | CC0 | Western + European medieval |
| Poly Pizza | CC0 / CC-BY (per-asset) | Strong on Asian, Mediterranean, African vernacular |
| Poly Haven Models | CC0 | Small but high quality |
| Sketchfab `@nebulousflynn` and other CC0 curators | CC0 | Mixed |
| BlenderKit free / CC0 section | CC0 | Mixed |
| OpenGameArt CC0 building packs | CC0 | Modular kits |

CC-BY assets require attribution in `ATTRIBUTIONS.md` (generated by
`build_custom_library.py`).

## Manifest schema (`sources.yaml`)

```yaml
version: 1
assets:
  - id: townhouse_03                       # filename stem
    source_url: https://polyhaven.com/a/some-townhouse
    author: Poly Haven contributor
    license: CC0
    region: europe                         # see _O4SFR_PATH_REGION_TOKENS for the set
    bucket: residential                    # residential|commercial|industrial|farm|accessory
    footprint_m: [9.0, 12.0]               # [width, depth] in metres -- model is rescaled to fit
    source_file: polyhaven/townhouse_03.glb
    height_m: 9.0                          # eaves height (informational; not enforced)
    decimate_target: 2000                  # optional, default 2000. Lower for tiny garages, raise for landmark scans.
    texture_max_px: 1024                   # optional, default 1024. Texture's longer side is capped here.
```

`decimate_target` and `texture_max_px` exist so high-poly photogrammetry scans
(typical Sketchfab models are 100k-1M+ tris with 4K textures) are auto-trimmed
before X-Plane sees them. Without these caps the sim can chew through VRAM
when 1000+ instances are placed per tile. Both are processed inside the
Blender headless step.

## Build steps

```
# 1. Convert all model inputs to X-Plane .obj (requires Blender + xplane2blender).
python scripts/asset_pipeline/convert_to_xplane_obj.py \
    --manifest scripts/asset_pipeline/sources.yaml \
    --blender "C:/Program Files/Blender Foundation/Blender 4.2/blender.exe" \
    --output  "C:/X-Plane 12/Custom Scenery/O4SFR_Library"

# 2. Emit library.txt + LICENSE + ATTRIBUTIONS.md from the manifest.
python scripts/asset_pipeline/build_custom_library.py \
    --manifest scripts/asset_pipeline/sources.yaml \
    --output  "C:/X-Plane 12/Custom Scenery/O4SFR_Library"
```
